🔒 Data Security & Retention Standards

  • Cryptographic Password Hashing: Passwords are never stored in plain text. They are hashed using PBKDF2 with SHA-512 and a unique 16-byte cryptographic salt per user.
  • Transport Encryption: All REST API requests run over HTTPS (TLS 1.3), and live multiplayer game packets stream over WSS (WebSocket Secure).
  • Immediate Erasure: When an account is deleted via Account Deletion, user records are immediately purged from active memory and disk storage without delay.
  • Offline Privacy: When playing offline or in airplane mode, no telemetry is generated or queued.
